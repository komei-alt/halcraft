# ハルクラ 非言語モブ効果音 収録・公開ガイド

## 収録方針

- オリジナル録音は、鳴き声、咆哮、唸り、息、クリック音、石・金属音、電子的な鳴きなど、意味のある言葉を含まない効果音だけを対象とする。
- 日本語を含むセリフ、挨拶、掛け声、案内、歌詞、意味の判別できる単語は収録・公開しない。
- 人が演技する場合も、発話者本人と保護者の公開同意を得る。原音、氏名、収録場所などの個人情報は Git と `public/` に置かない。
- 足音、環境音、戦闘音、乗り物音、UI音は、出所と利用条件を確認した高品質ライブラリ素材を基本とする。

## 必要な録音

| モブ | キュー | 内容 | 推奨テイク数 |
|---|---|---|---:|
| ゾンビ | `zombie.idle` / `alert` / `attack` / `hurt` / `death` | 徘徊の低い唸り、発見、攻撃、被弾、力が抜ける最期 | 各3〜5 |
| クモ | `spider.idle` / `alert` / `attack` / `hurt` / `death` | 顎・脚のクリック、威嚇、飛びかかり、被弾、停止 | 各3〜5 |
| ダーウィン | `darwin.idle` / `alert` / `attack` / `hurt` / `death` | 固有の鳴き、警戒、攻撃、被弾、死亡 | 各3〜5 |
| ニワトリ | `chicken.idle` / `alert` / `hurt` / `death` | 普段の鳴き、驚き、被弾、静かな死亡 | 各3〜5 |
| プロトタイプ | `prototype.idle` / `attack` / `hurt` / `spawn` / `special` / `death` | 電子的な鳴き、行動、被弾、復帰、特殊反応、停止 | 各2〜4 |
| ゴーレム | `iron_golem.idle` / `attack` / `hurt` / `spawn` / `special` / `death` | 石と金属の唸り、打撃、被弾、召喚、特殊反応、停止 | 各2〜4 |
| 巨大ボス | `boss_giant.idle` / `alert` / `attack` / `hurt` / `spawn` / `special` / `death` | 遠い咆哮、遭遇、攻撃、被弾、登場、段階変化、死亡 | 各3〜5 |

`spawn` は出現・召喚、`special` はボス段階変化や固有アクションに使う。録音が未登録のキューはゲーム内の非言語フォールバック音で再生される。

## 制作仕様

- 原音マスターは WAV、48 kHz、24 bit、モノラルで保存する。空間定位する音へステレオ残響を焼き込まない。
- ノイズ除去、不要な無音、クリック、DCオフセットを整え、ピークは -1 dBTP 以下にする。過度なコンプレッションやピッチ加工は避ける。
- ゲームへ配置するファイルは同じ内容の OGG と MP3 を用意し、拡張子を除いた同名ファイルにする。
- ファイル名は `public/audio/creatures/<mob>/<event>_01.{ogg,mp3}` の形式にし、個人名を含めない。
- `public/audio/creatures/manifest.json` の該当キューへ、`<mob>/<event>_01` のように拡張子なしで追加する。
- 配信前に `npm run audio:validate` を通し、`public/audio/ASSET_LEDGER.json` へ録音日・同意・加工担当・用途を個人情報なしで記録する。

## 演技基準

- 同じキュー内でも長さ、息、強さを少し変え、連続再生で機械的に聞こえない素材を用意する。
- 子どもが怖がりすぎない範囲で、敵は輪郭を明瞭にし、味方は柔らかく、ボスは低域と長い余韻で大きさを表現する。
- 人間の会話に聞こえる母音・子音の並びは避け、声を使う場合も動物・機械・物体の効果音として成立させる。
