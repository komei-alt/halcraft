# ハルクラ 全体仕上げビジュアル正本

このフォルダの4枚を、2026-07-24以降のゲーム内ビジュアルの実装正本とする。
外部作品の参照画像は、品質・構図・光の密度を判断する資料に限り、素材として複製しない。

## 画面ごとの責務

- `forest-gameplay.png`: 森林の密度、地表の細部、遠景の階層、夕方の逆光。
- `biome-board.png`: 森林・南国・雪原・砂漠の素材差と植生シルエット。
- `hud-vfx.png`: HUDの安全領域、スモークガラス、ブロンズ罫線、破壊・ヒット演出。
- `nether.png`: ネザーの暗部階調、溶岩の発光、寒色アクセント、壁越しに漏れない光。

## デザイントークン

- HUD背景: `rgba(9, 12, 14, 0.78)`
- HUD罫線: `rgba(232, 178, 78, 0.72)`
- HUD文字: `#fff4d2`
- HUD補助文字: `rgba(255, 238, 199, 0.72)`
- 暖色アクセント: `#f2b84f`
- 魔法アクセント: `#66e3ff` / `#a875ff`
- パネル角丸: 10px
- デスクトップのガラスぼかし: 12px（モバイル・Lowは無効）
- HUD中央安全領域: 画面幅の中央55%に常設パネルを置かない

## 実装上の固定事項

- ハル由来のキャラクター、建物、乗り物、固有モデルの形状・シルエットは変更しない。
- テクスチャとイラストは、ハルの色・モチーフ・物語を継承したスタイライズドPBRへ高品質化する。
- 葉・草花は輪郭が読めるアルファカットアウト、地面は粗さと微細法線、鉱石・金属は控えめな反射で区別する。
- 発光、粒子、ポータル、溶岩は常に深度判定し、壁や地面を透過させない。
- 近景の密度を優先し、遠景はLODと霧で整理する。品質向上のために植物ごとのReactノードを増やさない。
