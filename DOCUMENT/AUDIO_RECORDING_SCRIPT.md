# ハルクラ 家族収録台本・公開仕様

## 公開前ルール

- 収録参加者本人と保護者が、ゲーム内での一般公開に明示同意したテイクだけを使う。
- 原音、氏名、収録場所などの個人情報は Git と `public/` に置かない。
- ゲームへ入れるのはノイズ処理・音量調整済みの書き出しだけとし、メタデータを除去する。
- 各ファイルはモノラル 48 kHz、ピーク -1 dBFS 以下、セリフ間の無音を短く整える。
- 配信用ファイルを追加したら `dialogueCatalog.ts` の `audioPath` と `public/audio/ASSET_LEDGER.json` を同時更新する。
